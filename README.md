# 서울 고교 지도 만들기 — 진로교사 연수 안내

진로진학상담교사 연수에서 쓰는 실습 안내 페이지입니다. 학교알리미 공시자료와 Google 지도를 연결한 「서울 고교 지도」 웹앱을 만드는 과정을 네 단계로 나누어 담았습니다.

## 구성

1. Google AI 스튜디오의 Build 기능 열기
2. 준비된 프롬프트를 그대로 붙여넣기 (프롬프트 원문 1,632줄 포함, 복사 버튼 제공)
3. 학교알리미 인증키와 Google 지도 키 발급
4. 코드를 내려받아 Netlify에 배포하기

각 단계는 체크하며 따라갈 수 있고, 인쇄하면 단계별로 한 장씩 나옵니다.

## 파일

- `index.html` — 안내 페이지 전체. 외부 의존성은 글꼴(Pretendard) 하나뿐이고 나머지는 파일 안에 모두 들어 있습니다.

## 배포

정적 페이지 하나이므로 별도 빌드 과정이 없습니다. Cloudflare Pages나 Netlify에 이 저장소를 연결하면, 빌드 명령은 비워 두고 출력 폴더를 저장소 최상위(`/`)로 지정하면 됩니다.
